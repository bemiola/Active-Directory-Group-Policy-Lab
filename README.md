# Active-Directory-Group-Policy-Lab

Active Directory & Group Policy Home Lab
Overview
A hands-on Windows Server lab for practicing Active Directory Domain Services (AD DS), identity and access management, Group Policy administration, PowerShell automation, software deployment, and SMB file-share security.
> Status: In progress. Sections below are learning objectives and should be marked complete only after testing.
Objectives
Install and validate Active Directory Domain Services and DNS.
Manage users, groups, organizational units (OUs), and domain-joined computers.
Create, scope, troubleshoot and verify Group Policy Objects (GPOs).
Explore GPO precedence, inheritance and security filtering.
Automate repetitive AD tasks using PowerShell.
Deploy test software to scoped computers.
Configure and test secured SMB network shares.
